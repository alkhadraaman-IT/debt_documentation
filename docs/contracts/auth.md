# عقد المصادقة

- Firebase Authentication بالبريد وكلمة المرور. يوفّر تسجيل الحساب والدخول والخروج واستعادة كلمة المرور.
- تُزال المسافات المحيطة بالبريد، وتُمرر كلمة المرور كما أدخلها المستخدم.
- يُرسل رابط التأكيد بعد التسجيل. عند تعذّر الإرسال يبقى الحساب مسجلاً وتتاح إعادة المحاولة من صفحة التأكيد.
- الحساب غير المؤكد يبقى ضمن صفحة التأكيد. زر «تحققت من بريدي» يعيد تحميل المستخدم ويجدد رمز الهوية عند التأكيد.
- يدير Firebase استمرار الجلسة. تُستعاد عند بدء التطبيق، وتُزال عند الخروج. لا يخزّن التطبيق كلمات المرور.
- لا تتاح الوجهة المحمية إلا لجلسة ببريد مؤكد. واجهة المسارات ليست بديلاً عن قواعد الوصول في Firestore.
- تخبر الاستعادة المستخدم بإمكانية إرسال الرابط بصورة عامة دون الكشف عن وجود الحساب.

## تشغيل المصادقة

فعّل Email/Password في Firebase Authentication وسجّل التطبيق على المنصة المستهدفة. عند استخدام إعدادات Dart، مرّر ملف JSON خاصاً بالمنصة إلى `flutter run --dart-define-from-file=<file>` والمفاتيح التالية فيه:

- `FIREBASE_API_KEY`
- `FIREBASE_APP_ID`
- `FIREBASE_MESSAGING_SENDER_ID`
- `FIREBASE_PROJECT_ID`
- `FIREBASE_AUTH_DOMAIN` (من إعداد تطبيق الويب)

عند وجود إعداد Firebase أصلي جاهز على Android أو Apple، يمكن بدء التطبيق من دونه. على الويب، أضف نطاق التشغيل إلى النطاقات المصرّح بها في Firebase Authentication.
